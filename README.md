# R-FedLayer : 데이터 이질성 환경에서의 강건성 분석 및 심층 방어 기법 제안

## 1. 프로젝트 개요 (Project Overview)

이 프로젝트는 서버–클라이언트 기반 연합학습 환경에서 발생하는 비표적(untargeted) 모델 중독 공격에 대해, 전역(global) 모델의 성능을 안정적으로 유지할 수 있는지 실험적으로 분석하는 것을 목적으로 한다. 연합학습은 학습된 모델 파라미터만 서버로 공유하여 데이터 프라이버시를 보호하고 통신 비용을 줄이는 전략이지만, 악의적인 클라이언트가 조작된 모델을 업로드하면 전역 모델 전체가 오염될 수 있는 취약점을 가진다.

기본적으로 모델 중독 공격에 강인하도록 설계된 **FedLayer 구조가 Non-IID 데이터 분포에서 여전히 성능 약화를 보이는 문제**에 초점을 맞춘다.클라이언트별 데이터가 서로 다른 분포를 가지는 Non-IID 환경에서는, 계층 단위 선별과 스코어링을 수행하는 FedLayer라도 전역(global) 모델의 정확도와 수렴 안정성이 감소하는 현상이 나타난다.

이를 해결하기 위해 확장 실험에서는 **“데이터 공유” 전략을 도입하여 Non-IID로 인한 성능 저하를 완화할 수 있는지**를 검증한다. 구체적으로는 일부 공통 데이터(예: 소량의 공유 데이터셋 또는 공용 미니배치)를 클라이언트/엣지 서버 간에 제한적으로 공유함으로써, 로컬 데이터 분포의 편차를 줄이고 FedLayer가 더 일관된 전역 모델을 학습할 수 있도록 유도한다.

## 2. 프로젝트 목표 (Project Goals)

1. 비교 알로리즘인 FedAvg와 FedPSO을 구현하고 R-FedLayer의 핵심 메커니즘인 부분 레이어 전송과 손실 기반의 승자 선정 방식을 정확히 재구현한다.

2. R-FedLayer를 기본 구현으로 삼아 Non-IID 강도를 점진적으로 높이며 성능과 강건성을 정량적으로 평가하고 추가적으로 강건성을 향상시키는 방법을 제안한다.
